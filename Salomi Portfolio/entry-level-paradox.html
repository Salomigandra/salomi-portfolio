Methodology & data notes: Data was collected from major US job boards (LinkedIn, Indeed, Glassdoor, Levels.fyi) using search filters for "entry-level" + "data analyst" + "analyst" across 10 metro areas. Experience requirements were extracted using keyword parsing on the job description text (e.g. "1–3 years", "minimum 2 years experience"). Salary figures represent median advertised compensation; non-disclosed salaries were excluded. Postings with contradictory signals (title says "senior" but filter says "entry-level") were excluded. Dataset spans January 2019 through December 2024. Analysis performed in Python using Pandas and NLTK; visualisations built with Chart.js.
